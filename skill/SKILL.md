# 视频制作流程

## 从选题到样镜

1. **导演方案。** 写出观众最后应懂的一句话，以及哪个画面动作能演给观众看。[六套叙事母版](../scripts/)提供拆拍思路。需要选画风时，从仓库根目录运行 `python3 tools/recommend_style.py "选题"`，打开候选的 `STYLE.md`。历史机制题材优先考虑已经在青苗钱试片验证过的[暖纸纸雕](../styles/paper-cut.md)。用户已指定的讲法、片长和画风可直接沿用。
2. **查证和分镜。** 需要新建分集时，从仓库根目录运行 `python3 tools/new_episode.py <分集目录> --title "选题" --template D --seconds 45`。用 `facts.md` 给人物、年份、数字、引文和关键机制配出处，再写 `narration.json`。在 `storyboard.md` 用同一拍号记录画面动作、旁白锚点和静音时能读到的信息。按目标片长合并或扩展母版的拍数。用「情境示意」等字样注明推演、复原和假设画面。
3. **选择制作方法。** 先明确每个镜头要让观众看到什么、关键动作发生在什么时候。根据题材、现有素材和交付需求选择实拍、素材剪辑、代码动画、三维渲染或 AI 生成。一支片可以混用多种方法。需要选实现或导出方式时，查[制作路线](production-routes.md)。
4. **核对交付。** 按用户指定的阶段交付脚本、预览或成片。需要做样镜时，挑一个承担叙事的镜头，先看静音播放能否读懂动作顺序和结果，再按实际旁白对齐动作、音效和字幕。检查事实与画面是否一致，核对关键时间点和结尾留读。外部生成、用音和发布遵循该期已经明确的授权。

## 复用资料

- 从[风格索引](../styles/)查配色、构图和动作语言，再按当前镜头选实现。查[组件库](../components/)时，读对应条目的依赖与接入方法。
- 要复用对话中的制作要求时，打开[提示词](../prompts/)复制相应模板。给画面配动作音时，查[音效目录](../sound-effects/)里的来源和合成做法。
- 要将原创做法收回库时，保存可编辑源码、原片时间区间、用于验收的画面变化，以及新项目允许替换的内容。声明代码和素材的来源。
- [来源和导入范围](../sources/)记录原始版本、许可和本地改写。
