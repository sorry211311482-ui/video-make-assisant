# 视频制作路线

从分镜里的关键动作、镜头时长和交付要求选实现。一支片可以用实拍做主体、用代码做图解，再配独立音轨。每条路线按实际项目选择素材、预览和导出方式。

| 镜头或素材需要 | 可用做法 |
| --- | --- |
| 实景、人物或已有素材 | 实拍与剪辑。按分镜安排入点、出点和画外音。选用 AI 视频时，也可把生成片段放进同一剪辑时间轴。 |
| 二维图解、地图或道具流转 | SVG、Canvas 或现有动画组件。按镜头需要选择代码实现或 HyperFrames 项目，组件依赖见[接入说明](../components/)。 |
| 有空间关系的剖面、器物或运镜 | 用 Three.js 建场景，以镜头时间控制相机、物体和光照。 [Three.js 场景指南](https://threejs.org/manual/pages/creating-a-scene.html) |
| 手绘线条、排线或水彩质感 | 用 p5.js + p5.brush 绘制笔触与填色。通过笔尖位置、线条出现时机和留白引导视线。 [p5.brush](https://github.com/acamposuribe/p5.brush) |
| 背景底稿与纸张纹理 | 选用 Nano Banana Pro 时，可把静态底稿与纸纹各自保存，合成时分别裁切或叠用。 [Nano Banana 图像生成](https://ai.google.dev/gemini-api/docs/image-generation) |
| 落印、翻纸或道具碰撞音 | 需要可调的短音效时，助手可以写 Node.js 程序合成 WAV。声音起点对齐动作发生时间，力度和时长可按镜头调整。 [音效目录](../sound-effects/) |

## 推荐路线 · 代码逐帧 + FFmpeg

适合需要精确控制动作、单独重做镜头或按帧对齐音效的代码动画。

1. 选定画幅、帧率和镜头时长。用帧号计算时间，`第 n 帧的时间 = n / fps`，帧号从零开始。30 fps 下，帧号 54 对应 1.8 秒，落印声也可以放在这时。
2. 在绘制前加载图片、纹理与字体。需要可重复的随机变化时固定种子。笔触逐帧累积的镜头，从同一初始状态按帧顺序绘制。
3. 选用编号图像序列或直接把帧送入 FFmpeg。按分镜裁接画面，加入旁白和音效，再导出所需格式。抽查关键帧、片长和音画同步。 [FFmpeg 图像序列文档](https://ffmpeg.org/ffmpeg-formats.html)

剪辑软件或其他制作工具可以按各自的流程导出。需要合并不同来源时，把它们放到同一时间轴，核对画幅、片段边界和声音起点。
